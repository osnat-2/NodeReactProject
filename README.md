# NodeReactProject

A full-stack web application for managing products, user authentication, and a shopping basket. The project combines a Node.js API with a React frontend to provide a simple e-commerce experience.

## Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- React
- Redux Toolkit
- JWT authentication
- PrimeReact / CSS
